# 🎓 FIMAP - Trabalho de Conclusão de Curso

> **FIMAP / Auxiliar Financeiro**
> 
> *A Fimap é uma aplicação destinada ao mercado financeiro que tem como público alvo pessoas com necessidades de manipular seu dinheiro de uma melhor maneira, assim como entender sobre questões financeiras de maneira orgânica.*
